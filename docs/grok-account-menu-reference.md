# Grok Bot デスクトップ UI リファレンス（アカウントメニュー）

観測日: 2026-09-03 (JST)
観測方法: Grok Bot.app (`com.anysphere.sand`) 実機操作 + macOS AX ツリー + スクリーンショット
目的: cloud-itonami app (`app-itonami/svelte`) のアカウントメニュー統合の参照仕様

## アカウントメニューの構成（左レール下部のアバターから開く）

| # | 項目 | アイコン | 動作 |
|---|---|---|---|
| 1 | 週間使用量 76% | ゲージ | 利用状況メーター。右シェブロン → 使用量詳細 |
| 2 | iOS版Grok Bot を入手 | スマホ | App Store への外部リンク |
| 3 | 設定 | 歯車 | 設定ビュー（アプリ内） |
| 4 | 情報 | ⓘ | 情報ビュー（バージョン・ライセンス・リーガル） |
| 5 | ヘルプセンター | ? | ヘルプビュー / 外部ドキュメント |
| 6 | フィードバックを送信 | 拡声器 | フィードバック送信フォーム |
| — | （区切り線） | | |
| 7 | サインアウト | ログアウト | セッション終了（破壊的操作） |

## 補足観測

- macOS メニューバー側にも同等の導線がある:
  - 「Grok Bot」メニュー → 設定…
  - 「ヘルプ」メニュー → ヘルプセンター / フィードバックを送信
- メニューはオーバーレイとして画面左中央に展開、背景はディム。
- アイコンレール: 上部にアプリロゴ、区切り、チャット一覧（通知バッジ付き）、
  下部にユーザーアバター（= メニューの開閉ボタン）。

## itonami cloud app への統合方針

- ヘッダー右端のアバターボタンから同一構成のドロップダウンを開く。
- 設定 / 情報 / ヘルプセンター / フィードバック はアプリ内ビュー（モーダル）として
  統合し、外部遷移は作らない（Grok の外部リンク導線は入手/ヘルプのみ）。
- 週間使用量は simulation store の状態（superstep 進捗）を permille 表示に置き換え。
- サインアウトは確認ダイアログ必須（破壊的操作）。
